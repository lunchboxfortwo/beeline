# Pill faces truth

Reproduction R1 from #apm: an agent message to Ruby, then lunchboxfortwo
stopping Grunt, folded into one pill.

- Before: the Beeline ring, lunchboxfortwo and the sending agent. Opened, no
  entry has the Beeline face. Ruby and Grunt are pushed out.
- After: lunchboxfortwo, the sending agent and Ruby. No Beeline ring.

The page was a temporary esbuild + react-native-web page (not committed) that
renders the production `PillRow` over the R1 fixture. The "before" captures used
`PillRow.tsx` from `main`. The text uses the browser's fallback font, not
Space Grotesk; only the faces matter here. Bone and Obsidian, at phone width
(390 px) and desktop web width (1100 px).

Files: `before-{phone,web}-{bone,obsidian}.png`, `after-{phone,web}-{bone,obsidian}.png`.
