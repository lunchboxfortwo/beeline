# Agent run pills

Before/after captures of one chat that holds a 1→1 run (2 messages), a 1→5
fan-out, a many-to-many run with an agent stop inside it (7 messages, opened in
the after captures), and a person stop. Bone and Obsidian, at phone width
(390 px) and desktop web width (1100 px).

The page was a temporary Expo web route (not committed) that renders the
production `LedgerEntry`, `foldPillRuns` and `TranscriptPills` components over
fixture messages. Faces come from `IdentityMark` with the fixture seeds. The
"before" captures used the three source files from `main` (9ea8aa064).

Files: `before-{phone,web}-{bone,obsidian}.png`, `after-{phone,web}-{bone,obsidian}.png`.
